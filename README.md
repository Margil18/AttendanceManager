# AttendanceManager

----------------------------------------Attendance Manager System-------------------------------------------------
-------------- Description---------------
The Attendance Manager System is a desktop application built using C# and .NET Framework to manage and track attendance records for employees or students. It allows users to log in, mark attendance, view daily/monthly reports, and store all data securely in a SQL Server database.

-------------Technologies Used--------------
Language: C#
Framework: .NET Framework / .NET Core
Database: Microsoft SQL Server
UI: Windows Forms (WinForms)
IDE: Visual Studio
Data Access: ADO.NET
-----------------Workflow-------------
Login: Users log in with valid credentials.
Dashboard: Provides options to manage employees/students and mark attendance.
Manage Records: Add, edit, or delete employee/student details.
Mark Attendance: Record daily attendance with Present/Absent/Leave options.
View Reports: Generate and view attendance summaries and reports.

---------------Features-----------
Simple and clean interface
Secure login system
Daily attendance tracking
Data stored in SQL Server
Attendance reports and summaries
